[Ridiculous at First Glance, Real by the Second](https://make.fun/c/u-po-pu-ridiculous-at-first-glance-real-by-the-second-9a97d12a).

`main.py` (Python standard library only) writes one sentence — at most 200
characters — pitching a bizarre startup idea that sounds absurd until you
realise it would actually sell.

**Concept: AI Apology Service.** Companies pay for a service that writes
warm, human-sounding apologies from their chatbots to furious customers,
because a bot that says sorry properly keeps the customer.

Run it:

```sh
python3 main.py   # writes the pitch to /output/entry.txt
```
